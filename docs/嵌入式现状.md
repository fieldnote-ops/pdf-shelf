# 嵌入式现状

> 结论先行：《从内核到智能体》的第七篇「完整嵌入式系统」**尚未整合完整**。本仓库按「部分整合」记录，不把它当成品。

## 当前快照

- 载体：《从内核到智能体：系统原理解剖图解全集》，版本 2026.11，1140 页。
- 第七篇范围：书内 p991–1118，24 章 + 导读；其后是三个附录（p1119–1128），含「主卷与完整嵌入式篇的跨卷接口」。
- 主线：复位与启动 → 测量与样本 → RTOS → 控制与执行器 → 通信 → 低功耗 → 看门狗/OTA → 证据与端到端。
- 构建：Typst 0.15.1，`ALL_BOOK_PROFILE=full`。

## 「未整合完整」指什么

- 作者说明：嵌入式部分尚未整合完整。本版把它作为阶段性快照并入全集，所以 catalog 的 `status` 记为 `partial`，README 首屏也给出提示。
- 本仓库**不预填**「缺哪几章」：没有作者确认的缺口清单，写出来就是猜测。补全后更新本文件与 `status` 即可。
- 更新方式：新版本用新文件名发布，不覆盖本版；旧版归档到 GitHub Releases。
